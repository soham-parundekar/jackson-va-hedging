# Four packages, and each one earns its place.
#
# numpy and pandas do the work: the curve bootstrap is a forward substitution, the liability
# recursion steps an array of cohorts by paths a policy year at a time, and the regression proxy
# goes through numpy.linalg.lstsq.
#
# SciPy is used in three places that genuinely need it: least_squares for the Heston
# calibration, brentq for Black implied volatility and for the break-even fee, and the normal
# distribution in the Black-76 helpers. Writing those by hand would be worse code rather than
# more independent code.
#
# matplotlib draws the figures, which are built from the committed tables rather than from live
# model objects, so nothing else in the project depends on it.
#
# PyYAML is gone with the parameter file it was there to read. The modelling assumptions are now
# constants in the module that uses them, each with the reasoning beside it, because a second
# file listing the same numbers is a second thing to keep true.
#
# Numba is deliberately absent. The inner loop runs at most fifty-five times per valuation and
# the work inside it is already vectorised, so a compiled kernel would add a dependency, a
# compilation wait and a second code path to keep correct, and would save seconds.
#
# Version floors are the oldest releases this has been run against, not the versions it was
# developed on. Floors rather than pins, which is a decision and not laziness. A pin would
# promise that a rerun reproduces the committed tables to the byte, and the measurements in the
# Reproducibility section of docs/data_sources.md say it does not: the libraries move results in
# their last stored digits, and in one place - the nested convexity surface's node selection -
# that is enough to pick a different path at the same moneyness. A pin would also have to name
# the versions the committed tables came from, and that set is no longer recoverable, so any
# pin written here would be an assertion about provenance rather than a record of it. What is
# recoverable is the size of the differences, which is measured per pipeline stage and written
# down. Read the tolerances there instead of trusting a version string.
